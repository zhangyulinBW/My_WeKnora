docker compose up -d   # 启动核心服务

# 快速开发启动
## 启动基础设施
./scripts/dev.sh start

## 启动后端（新终端）
./scripts/dev.sh app

## 启动前端（新终端）
./scripts/dev.sh frontend

## 查看日志
./scripts/dev.sh logs

## 停止所有服务
./scripts/dev.sh stop
